# 登录界面 3D 空间感升级方案

> 目录：`原型/登录页3D方案/`　｜　对应线上页面：`http://192.168.3.38:18444/login`
> 状态：**仅设计稿，未改动任何业务代码**（`grade-business/web/src/views/SignIn.vue` 等保持原样）
> 版本：v2（纵深强化 + 指挥舱信息层）

---

## 一、一句话结论

把现在「一张登录卡片 + 一个悬浮盾牌」升级为**一间有纵深的安防舱室**：
盾牌是舱室中央的立体核心，登录舱是舱室右侧的控制台，
四周悬浮的全息面板与贯穿全屏的透视地面网格负责建立空间感与纵深。

**不新增任何业务字段，不新增美术资源**，只是把现有元素从"平铺"变成"分层"。

### 3.2 Z 轴分层（纵深的核心）

`perspective` 只挂在 3D 容器上（`.scene` 1200px / `.floor-wrap` 1500px），DOM 层级决定绘制顺序：

| 层 | 位置 | 内容 |
|---|---|---|
| 前景 L2 | translateZ +160px | 倒刺棘轮轨道环（锥形渐变青+红，穿过盾牌前方） |
| 前景 L1 | 0 | 粒子环 A/B（40 + 28 个发光节点）、盾牌、光柱、悬浮光池 |
| 中景 | translateZ −60px | 全屏透视地面网格（2800×2800，`rotateX(75deg)`，`perspective-origin` 落在网格中心） |
| 扫描波 | 基座之后 | 3 圈柔光环从平台**后方**贴地扩散（`rotateX(85deg)`），不压在平台正面 |
| 基座 | 0（更低 Y） | 等保基座 + 红色地面反光 |
| 背景 L0 | DOM 最底 | 太空背景图、点阵网格、3 条蓝色数据光带、低空体积雾、顶置光锥 |
| UI 层 | 扁平上下文 | 全息面板、登录舱卡片、四角切角、HUD 锁定框、顶部指挥条、底部标语 |

> ⚠️ **实现约束**：HUD 锁定框（`CORE-01 / 等保三级`、`AES-256 · SM2`、`UPLINK OK`）必须放在 3D 上下文**之外**。
> Chrome 在整幅视口截图（`Page.captureScreenshot` 无 clip）时会丢弃 `transform-style:preserve-3d` 子树中的文字图层，
> 裁剪截图则正常 —— 设计稿渲染与前端实现都应把 HUD 文本放在扁平层。

### 3.4 动画时间轴

**环境动效（循环版，8s 无缝周期，所有频率都是 8s 的约数）**

| 元素 | 运动 | 周期 |
|---|---|---|
| 盾牌 | `rotateY(-20°±11°)`、`rotateX(4°±2.6°)`、上下浮沉 ±15px | 8s / 8s / 4s |
| 光晕 | 强度 0.42↔0.58 呼吸 | 4s |
| 倒刺轨道环 | `rotateZ` 22°/s，26 枚尖刺 | 8s |
| 粒子环 A/B | 旋转 36°/s、-24°/s，节点呼吸缩放 | 8s / 8s |
| 数据光带 | 3 条高光横向流动 | 6s（错相 0/.42/.76） |
| 扫描环 | 3 圈柔光环自平台后方贴地扩散（径向渐变环，非描边） | 2s（错相 1/3） |
| 光柱 / 悬浮光池 | 强度与位移呼吸 | 4s |
| 全息面板 | 指标数值微幅波动、26 点波形实时重绘、进度条 55%↔93% | 4–8s |
| 地面网格 / 体积雾 / 顶光 | 静态（提供透视与空气参照） | — |

**交互流程（6s 单次播放）**

| 时间 | 事件 | 状态变化 |
|---|---|---|
| 0–0.7s | 光标移入用户名框 | — |
| 0.8–1.6s | 输入 `ops.admin` | 用户名聚焦光晕 |
| 1.7–2.0s | 光标移向密码框 | 用户名失焦 |
| 2.1–2.9s | 输入密码（10 位掩码） | 密码聚焦光晕 |
| 3.0–3.3s | 光标移向登录按钮 | 按钮提亮 |
| 3.5s | 点击 | 按钮按压回弹 |
| 3.5–4.5s | 认证中 | 按钮转圈 + 顶部"身份校验中" + 基座灯转橙 + **光柱拉满、轨道环提速至 70°/s** + 副标题"正在校验授权账号与国密签名" |
| ≥4.5s | 认证通过 | 基座灯转绿、盾牌增亮 1.25×、绿色凭据条滑出、副标题"认证成功，正在进入平台"、提示语"防护舱已激活" |

### 3.6 验收标准

1. 1920×1080 下盾牌、基座、登录舱三者视觉主次清晰；登录舱正文 ≥ 13px，HUD 标签 ≥ 10px 且不被 3D 层遮挡。
2. 8s 循环版首尾帧一致，无跳变。
3. 认证流程 4 态（idle / 输入中 / checking / success）视觉区分明确，checking 时光柱与轨道有明显联动。
4. 全息面板指标与波形持续变化，无闪烁、无跳数。
5. 1440×1080 与 1920×1080 下布局不塌；≤1280 时沿用线上单列回退策略。
6. 不新增外部依赖、不新增美术资源、无网络请求。
7. `prefers-reduced-motion` 时关闭粒子环与扫描环（沿用线上既有降级思路）。

## 四、产物与复现

| 文件 | 说明 |
|---|---|
| `index.html` | 可交互设计稿（浏览器直接打开自动播放；`?mode=loop` / `?mode=flow` 切换动效，`?manual=1` 关闭自动播放） |
| `assets/` | 从线上扒下来的 3 套官方素材（盾牌 / 基座 / 太空背景） |
| `out/登录界面3D-空间动效循环.gif` | 960×496，8s，12fps，无缝循环 |
| `out/登录界面3D-交互流程.gif` | 1024×530，6s，12fps，单次播放（输入 → 认证 → 通过） |
| `out/登录界面3D-静帧-1920.png` | 1920×1080 静帧效果图 |
| `out/登录界面3D-认证通过-1920.png` | 1920×1080 认证成功态静帧 |
| `tools/capture.mjs` | CDP 驱动 Chrome 逐帧截图（确定性时间轴，不依赖真实时钟；`Emulation.setDeviceMetricsOverride` 固定 1920×1080） |
| `tools/build_gif.py` | 帧序列 → GIF（全局调色板 + 帧间差分 + 降采样） |

```bash
cd 原型/登录页3D方案/tools
node capture.mjs loop 8000 20 out/frames_loop     # 捕获循环帧
node capture.mjs flow 6000 15 out/frames_flow     # 捕获交互帧
python3 build_gif.py ../out/frames_loop ../out/登录界面3D-空间动效循环.gif \
        --width 960 --fps 12 --colors 96 --seconds 8 --blur 0.35 --loop 0
```
