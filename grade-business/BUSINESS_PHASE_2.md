# 等保业务第二批开发目标

沿用 Vue 3、Go `net/http` 和 PostgreSQL。扩展管理端等保业务，在独立测试库完成开发后的统一验收。本批仍采用本机回环运行方式。

- [x] 实施管理。实现常规、变更报备以及初审、终审、监管复核，支持详情、状态查询和操作留痕。按原型限制同一备案每自然年最多两次有效变更，提交后 24 小时内且未受理可撤销。迁移 `004_implementations.sql`，管理端入口 `/implementations`。
- [x] 备案变更与注销。已通过且有效的备案可登记申请，申请单独保存并支持初审、终审、退回补正。草稿或退回申请可撤回，原记录仍可查询。变更终审通过后更新主记录，保留原值及审核历史。注销终审通过后停止发起新业务，既有业务仍可追溯。迁移 `005_filing_lifecycle.sql` 和 `008_filing_application_withdrawal.sql`，管理端入口 `/filing-applications` 和备案详情。
- [x] 整改规划。关联已通过的测评报告，录入措施、责任和期限并上传三类必备材料。首次上传材料后锁定关联报告。支持提交、退回、重提、审核、期限筛选和实时统计。迁移 `006_remediations.sql`，管理端入口 `/remediations`。
- [x] 测评报告提取。为带栏目标题的 DOCX 文件提供本地解析、原文出处、人工校对和版本留痕。迁移 `007_report_extractions.sql`，入口在已有测评详情。
- [x] 完成统一联测。四个增量模块一并验证，并回归备案、测评和知识库。检查真实 PostgreSQL 上的状态、附件范围、审核历史和并发写入。Chrome 核对四个模块，实际提交实施受理和报告校对。Go 全包竞态检查、前端类型检查与生产构建通过。
