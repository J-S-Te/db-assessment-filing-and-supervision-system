# 管理端原型 V2 对照与落地

页面参考为[管理端原型 HTML](../原型/管理端/index.html)及其[设计样式](../原型/管理端/styles.css)，[导航结构 V2](../信息架构与导航结构V2.md)用于核对模块归属。原型目录中的 P0 和 P1 截图用于关键页面的版式复核。HTML 体现交互和结构，截图体现对应状态下的视觉呈现。

| 业务路由 | V2 模块 | 关键对照 |
| --- | --- | --- |
| `/` | M1 工作台 | 工作台待办表、统计卡、关键指标、临期提醒、快捷入口 |
| `/filings`、`/filing-applications` | M2 等级保护 · 备案管理 | 全部及变更注销视图、备案录入、材料详情和审核 |
| `/implementations` | M2 等级保护 · 实施管理 | 实施报备、不同报备阶段、录入、审核与留痕 |
| `/reports` | M2 等级保护 · 测评管理 | 工具栏、报告列表、报告提取与附件详情 |
| `/remediations` | M2 等级保护 · 整改规划审核 | 四张统计卡、查询工具栏、审核、详情及同步台账 |
| `/hazards` | M3 全息档案 · 隐患管理 | 系统漏洞台账、状态、复核动作及详情 |
| `/knowledge` | M5 智能体 · 知识库 | 分类页签、搜索、条目列表和详情 |

本轮范围为已有业务链路。通用侧栏宽 232 px，顶栏高 56 px，沿用 V2 主色、背景色、工具栏、模块页签及遮罩。详情和录入使用原生对话框，支持直接打开业务地址。详情关闭后保留来源列表的筛选和游标。

工作台、列表和详情读取真实测试库。备案、实施和报告等尚未设置审核期限的待办显示空值。实施周期使用计划日期，隐患台账显示实际登记时间。隐患状态名称在列表、详情、留痕和提醒中统一。测评材料分类沿用当前上传规则。分页使用服务端游标，列设置作用于当前列表。原型中的活跃预警、等保覆盖率、页签计数等演示数据，以及批量导入、合规比对、M4/M6/M7 等未接通能力仍有差异。[业务流核对](BUSINESS_GAPS.md)

## 本地复核

- Chrome 在同一桌面窗口尺寸下对照了原型与测试版的工作台，核对了原型备案工具栏及测试版列表布局。依次打开八个业务入口，验证备案列开关、变更和隐患详情返回后的筛选、实施录入、测评详情的抽取、审核留痕与附件页签、整改规划详情、隐患嵌套复核及知识库详情和新增窗口。
- 隔离构建通过 TypeScript 类型检查、3 项前端单测、Go 全包竞态测试及 `go vet ./...`，跨包语句覆盖率 72.7%。8 个直达地址与 53 个静态文件和最终构建一致。独立 PostgreSQL 测试 schema 上，`tests/acceptance.py` 的 10 个业务接口批次通过。
- 桌面布局完成实测。逐像素比对、其他视口及原型未接通页面仍待验证。
