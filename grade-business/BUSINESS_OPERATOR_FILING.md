# 运营者自主备案与换机构复测

本地预览使用 `127.0.0.1:18457`、独立 PostgreSQL 测试 schema 和独立材料目录。运营者从「我的备案办理」选择所属单位。测评机构按测评机构名称查看，监管端负责受理和审核。

## 自主备案

- 首报保存草稿后上传备案表和定级报告，再提交初审。退回时由运营者补正重提。机构可查看运营者自主备案和材料，监管审核状态、各端留痕和站内意见使用同一业务记录。
- 已通过且有效的备案可发起变更或注销。同一备案仅允许一笔未结申请，草稿、待初审、待终审、退回补正都占用该名额。草稿或退回申请按现有规则撤回后可重新发起。
- 本地材料口径要求变更说明或注销及数据留存或销毁说明，允许追加配套证明。监管可在详情查阅原件。材料类型校验和申请版本校验由服务端执行，监管通过时再次核对必传材料。
- 首报、变更和注销详情依据实际提交或审核通过记录生成 UTF-8 文本回执。注销终审后，三端显示已注销，原件和留痕仍可查。

## 换机构复测

- 从变更草稿确认备案和目标机构。变更详情会查找匹配的报备，并展示报备进度。发起实施报备时按备案 ID 精确预填，目标机构与原机构需不同。
- 变更实施沿用受理、初审、终审和监管复核。以每份备案的上海自然年计，变更额度为两次。首次提交后 24 小时内且未受理时，发起人可撤回并释放额度。
- 提交备案变更和两级审核通过均在事务中核对实施报备的备案、目标机构、类型和通过状态。变更终审时更新备案机构归属并消费报备依据。同一份通过报备只支持一次已生效换机构。既有待审换机构申请也需有匹配的通过报备才能继续审批。归属更新后，换入机构可沿用测评流程提交复测报告。
- 迁移 022 增加运营者业务通知、备案来源与查询索引。迁移 023 持久化申请材料、实施依据和消费约束。接口契约版本为 OpenAPI 1.12.0。

## 验收入口

- 用隔离 PostgreSQL 执行 `go test -race -count=1 -coverpkg=./... ./...`、`go vet ./...` 和管理端构建。
- 用 `pnpm --dir web typecheck`、`pnpm --dir web test`、`pnpm --dir web build` 验证前端。
- 在本轮独立预览执行 `GRADE_ACCEPTANCE_PORT=18457 python3 -B tests/operator_filing.py`，覆盖自主首报、普通变更、换机构复测、注销四组业务。原业务回归使用 `tests/first_submission.py` 和 `tests/acceptance.py`。
- Chrome 核对两类首报材料、回执下载、状态自动同步、复测条件和关联预填、监管材料与审批、改派归属及注销。
